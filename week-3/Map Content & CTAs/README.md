# The Through-Line: Map Content & CTAs

**Track:** General AI Fluency  
**Week:** 3  
**Phase:** Foundations  
**Assignment:** The Through-Line: Map Content & CTAs

## Overview

This assignment maps the content and structure of my future portfolio before the building phase.

The goal is to create a clear connection between:

**My claim → My strongest work → Evidence → Experience → Call to Action**

The portfolio should not simply list my skills. It should demonstrate what I can build through projects, internship experience, technical contributions, and evidence.

---

## One-Line Claim

> I build practical AI-powered software that turns real-world problems into useful, user-focused solutions.

---

## Primary Call to Action

**Contact Me**

All other calls to action should eventually guide visitors toward this primary action.
