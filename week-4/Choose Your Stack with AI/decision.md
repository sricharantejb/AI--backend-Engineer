# Final Decision

## Chosen Stack

I chose:

**React + Vite + JavaScript + CSS**

### Hosting

**Vercel**

### Backend

**Not needed yet.**

---

# Why I Chose It

I chose React + Vite because it gives me a good balance between simplicity and flexibility.

I already have experience with React, JavaScript, and Vite, so I do not have to spend most of the two-week build period learning a completely new stack.

The portfolio needs to show projects, screenshots, case studies, GitHub repositories, live demos, internship experience, and long-form content. React is well suited for creating reusable components for all of these.

It is also free to host on platforms such as Vercel.

Most importantly, **can I maintain this?**

Yes.

I understand the basic technologies involved, and I can continue adding projects and improving the website without needing a complicated backend or infrastructure.

---

# Why I Did Not Choose HTML + CSS + JavaScript

This was the simplest option.

I considered it seriously because it is free, easy to deploy, and does not require a backend.

However, my portfolio will have multiple pages, project case studies, reusable project cards, image sections, experience sections, and other repeated UI elements.

React will make this easier to organize and maintain.

So I decided that plain HTML/CSS/JavaScript would be simpler initially but less convenient as the portfolio grows.

---

# Why I Did Not Choose Next.js + TypeScript + Backend

Next.js would give me more power and flexibility.

However, I currently do not need:

- A database
- Authentication
- Complex APIs
- Server-side application logic
- Dynamic content management

Choosing the most powerful stack would add unnecessary complexity.

I would have more technologies to learn and maintain while trying to finish the portfolio.

For this project, I would rather use that time to improve the actual content and presentation of my work.

---

# Can I Maintain This?

**Yes.**

React + Vite is within my current skill set, and I can maintain the project myself.

I can add:

- New projects
- New case studies
- New screenshots
- New experience
- New skills
- GitHub links
- Live demos

without needing to redesign the entire technical structure.

---

# Does It Show My Work Well?

**Yes.**

The chosen stack can properly display the type of work I want to showcase.

It supports:

- Image galleries
- Project screenshots
- Long-form case studies
- GitHub repository links
- Live demos
- Technical architecture diagrams
- Internship experience
- Skills
- Contact information

This makes React + Vite a good fit for the actual purpose of my portfolio.

---

# Final Decision

| Option | Decision | Reason |
|---|---|---|
| HTML + CSS + JavaScript | Not chosen | Simple, but less convenient to maintain as the portfolio grows |
| React + Vite + JavaScript + CSS | **Chosen** | Best balance of familiarity, flexibility, maintainability, and presentation |
| Next.js + TypeScript + Backend | Not chosen | More powerful than currently required and adds unnecessary complexity |

## Final Stack

**Frontend:** React + Vite + JavaScript + CSS

**Hosting:** Vercel

**Backend:** Not needed yet

**Database:** Not needed yet

**Primary Goal:** Build a maintainable portfolio that presents my projects and experience effectively.
