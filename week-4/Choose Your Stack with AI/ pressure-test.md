# Pressure Test

## Front-Runner

My front-runner is:

**React + Vite + JavaScript + CSS**

Hosted on:

**Vercel**

---

# What Breaks If I Pick the Simplest Option?

The simplest option is:

**HTML + CSS + JavaScript**

It would still work for my portfolio.

I could display:

- Projects
- Screenshots
- GitHub repositories
- Live demos
- Case studies
- Internship experience
- Contact information

However, managing a larger portfolio manually would become less convenient.

Reusable components would need to be handled manually, and maintaining multiple pages could become more difficult.

So the simplest option is possible, but it is not the best fit for how I want to structure the portfolio.

---

# What Do I Maintain If I Pick the Most Powerful Option?

The most powerful option is:

**Next.js + TypeScript + Backend/API**

I would gain more flexibility, but I would also need to maintain more technology.

This could include:

- Next.js
- TypeScript
- Dependencies
- API routes
- Backend logic
- Possible database
- More complex deployment
- More complex project structure

For my current portfolio requirements, most of these features are unnecessary.

I would spend more time maintaining the technology instead of improving the portfolio content and project presentation.

---

# Can I Finish in Two Weeks?

## HTML + CSS + JavaScript

**Yes.**

It is the easiest option to finish quickly.

## React + Vite

**Yes.**

I already have experience with React and Vite, so I can build the required portfolio within two weeks without introducing too much complexity.

## Next.js + TypeScript + Backend

**Possible, but unnecessary risk.**

I could potentially finish it, but I would have more things to learn and maintain.

---

# Does It Show My Work the Way It Needs to Be Shown?

## HTML + CSS + JavaScript

**Yes.**

It can display all the required content, but building and maintaining the structure manually is less convenient.

## React + Vite

**Yes.**

This is a strong match for my needs.

React makes it easy to create reusable:

- Project cards
- Case-study sections
- Image galleries
- Experience sections
- Navigation
- CTA components

It can also link to GitHub repositories and live demos.

## Next.js

**Yes.**

It can display everything I need and more, but the additional capabilities are not necessary right now.

---

# Backend Decision

A backend is **not needed yet**.

My current portfolio is primarily a content and project showcase.

I do not currently need:

- User authentication
- User accounts
- Database storage
- Admin dashboard
- Server-side application logic

If I later need dynamic functionality, I can add a backend or API without needing to rebuild the entire portfolio from scratch.
