# FL-02 - Prompt Engineering Ladder

## Overview

This assignment is part of the General AI Fluency track.

The goal of this assignment was to learn how to improve AI prompts step by step by adding one prompt engineering technique at a time and comparing the results.

## Objectives

- Understand prompt engineering
- Compare weak and improved prompts
- Learn how each prompt layer affects AI responses
- Create a reusable prompt for future tasks

## Prompt Engineering Layers Used

1. Clear Goal
2. Audience
3. Context
4. Output Format
5. Quality Criteria

## Deliverables

- Prompt Ladder document
- Baseline prompt
- Five improved prompt versions
- Output comparison for each version
- Final reusable prompt

## Learning Outcome

Through this assignment, I learned that small improvements to a prompt can significantly improve the quality of AI-generated responses. By adding one layer at a time, I was able to understand which prompt engineering techniques produced the most useful results.
