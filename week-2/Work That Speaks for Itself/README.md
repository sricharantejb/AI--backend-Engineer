# FL-03 - Frame It as Cases

## Overview

This assignment focused on presenting my project as a case study instead of simply showing code or screenshots.

## Objectives

- Create a personal voice card
- Use AI to interview me about my project
- Write a case study using my own words
- Edit the content to sound natural and personal

## Deliverables

- Voice Card
- Project Case Study
- Bio
- Contact / Call to Action
- Before and After Example

## Learning Outcome

Through this assignment, I learned how to explain my work by describing the problem, the decisions I made, and the final outcome. I also learned how AI can help organize my ideas while still keeping my own voice.
