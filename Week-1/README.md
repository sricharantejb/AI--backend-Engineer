## Technologies Used

## Project Files

- `app.py` - Main Flask application
- `.gitignore` - Ignores unnecessary files

## How to Run

1. Install Flask

```bash
pip install flask
```

2. Run the application

```bash
python app.py
```

3. Open your browser and visit

```
http://127.0.0.1:5000/
```
