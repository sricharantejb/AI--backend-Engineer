# How to Add the Next Case Study

## Where it goes
Add the next case study to the portfolio's **Projects / Case Studies** section as a new project entry using the existing visual structure.

## Three-beat structure

### 1. Problem
Explain what problem the project addressed, who/what was affected, and why it mattered.

### 2. What I Did
Describe my actual contribution, architecture and implementation decisions, technologies, challenges solved, and individual role.

### 3. What Came of It
Show what was built, measurable or demonstrable outcomes, real screenshots, lessons learned, and repository/demo links.

## Repeatable process
1. Select the completed project.
2. Collect real screenshots/captures.
3. Write the Problem section.
4. Write my specific contribution.
5. Record the outcome and strongest evidence.
6. Add the case using the existing portfolio layout.
7. Check images for legibility and consistency.
8. Add repository/demo links.
9. Proofread.
10. Publish.
11. Preserve project/context files for future updates.

## Quality check
- [ ] Concrete problem
- [ ] My contribution is clear
- [ ] Outcome is evidence-based
- [ ] Real captures are used
- [ ] Existing portfolio structure is followed
- [ ] Links work
- [ ] No secrets/private credentials are included
